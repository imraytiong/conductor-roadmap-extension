# Milestone: v0.2 Release

**Status:** NOW
**Created:** 2026-04-05
**Updated:** 2026-04-05

## Objective
Address a concurrency bug discovered during dogfooding where multiple CLI tools attempting to update `ROADMAP.md` at the exact same millisecond can cause a race condition, leading to partial overwrites or duplicated text.

## Scope
- Implement file-locking or atomic writes in `promote_milestone.cjs` (and other related scripts that modify `ROADMAP.md`).
- Add basic retry logic or backoff if the roadmap file is locked.
- Release version `0.2.0` once validated.

## Technical Notes
- Can use simple lockfiles (`ROADMAP.lock`) or `fs.writeFileSync` tricks to manage concurrent updates from parallel shell processes.
